OrangeHRMS in-place stability patch

Apply this overlay to the existing D:\OrangeHRMS project. It contains only these changed source files:
- fixtures/baseFixture.js: successful login fixture now waits for dashboard URL and heading.
- pages/AdminPage.js + tests/admin.spec.js: A04/A05 no longer depend on hardcoded employee names from shared demo data; duplicate username check blurs the field; mismatch flow can select any available employee.
- tests/myInfo.spec.js: MI03 asserts required errors immediately after clear/blur and never submits the public employee form.
- pages/RecruitmentPage.js: Date of Application input is located by its field label instead of an exact placeholder string.
- tests/recruitment.spec.js: R06 candidate identity is unique per run because created candidates persist in the shared demo.

Not included/changed: playwright.config.js, package.json, package-lock.json, Allure config/reports, Excel workbooks, JSON test data, constants, hooks, LoginPage, CommonMethods.

Run after copying files:
1) npx playwright test --list --project=chromium
2) npx playwright test --project=chromium --workers=1

This patch passed local static syntax checks and a text audit. It has not been browser-tested against the public demo from this environment.
